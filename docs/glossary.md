# 术语与选购常见问题

[← 返回首页](../README.md) · [新手路线](getting-started.md) · [官方证据](evidence.md)

## 把几个容易混淆的词拆开

| 名称 | 本指南中的含义 | 购买时要追问 |
| --- | --- | --- |
| 静态 | 目标网站看到的出口在约定期间保持固定 | 维护、到期或更换地区会不会换 IP |
| ISP / 静态住宅 | 商家对地址网络归属的产品分类 | ASN、地区、具体产品类型，检测数据是否一致 |
| 独享 / Dedicated | 出口 IP 的独享约定 | 独享的是 IP、端口，还是只有账号 |
| 共享 / Shared | 同一出口可能有其他使用者 | 是否共享、人数或限制能否书面确认 |
| Private | 不同商家的定义可能不同 | 是否等同 Dedicated，不能仅凭名字判断 |
| 固定网关 | 你连接商家的主机或入口地址固定 | 最终出口是否也固定 |
| FUP | 公平使用规则 | 周期、阈值、超额计费或限速、恢复时间 |
| 并发 | 同时存在的连接或请求限制 | 按账号还是按 IP 计算，具体计数方式 |
| IP 白名单 | 按连接来源 IP 放行 | 是否应填写入口线路的公网 IP，切入口后如何更新 |
| 链式代理 | 一个代理借助另一个代理连接 | 最终出口是谁，规则是否真的命中 |

商家标签与第三方数据库可能不一致。记录检测时间和来源，也要测试实际用途。

## 1 个 IP 的月费怎么比较？

先看**本次实际要支付的总额**。例如，10 个 IP 共 $35，只能说明平均 $3.50/IP；它不自动意味着可以支付 $3.50 买一个。共享产品、独享产品、流量计费和套餐额度也要分开比较。

建议记录：`国家 + 数量 + 租期 + 独享属性 + 总价 + 税费 + FUP + 续费价 + 查询日期`。首页表格保留原始查询状态，新增入门文档不会自动刷新这些报价。

## 为什么还需要入口线路？

如果本地到 ISP 的连接不稳定或不可达，可以让已可用的入口连接 ISP。网站看到的是最后一跳 ISP。是否需要入口、入口能否连到 ISP，要实际验证；入口本身不通时，第二跳不能修好第一跳。

## SOCKS5、HTTP 与 HTTPS 是一回事吗？

不是。商家提供的 SOCKS5 和 HTTP 代理可能使用不同端口；目标网站的 HTTPS 描述网站连接，不能用来推断商家代理支持 TLS。按商家官方参数设置，不应通过关闭证书校验来掩盖错误。

相关定义与配置见 [Mihomo SOCKS](https://wiki.metacubex.one/config/proxies/socks/)、[HTTP](https://wiki.metacubex.one/config/proxies/http/) 和 [dialer-proxy](https://wiki.metacubex.one/config/proxies/dialer-proxy/) 文档。

## 检测页看到旧出口，说明链错了吗？

先检查检测域名是否也走了 ISP。示例默认只对列出的服务域名分流，普通检测页可能仍走入口。临时将检测域名加入 `extraDomains`，或按教程用全局链验证，再恢复原分流。

## 一个 IP 能让所有 AI 服务稳定可用吗？

不能由 IP 类型推出这个结论。分别验证目标服务、地区与账号资格、登录、消息、上传和实际客户端；首页可达、IP 评分或命令行 200 都只是局部观察。完整测试范围应写在记录中。

## 我该提交什么样的故障反馈？

提交日期、客户端版本、配置方式、入口能否单独使用、失败域名、错误提示，以及出口是否与预期一致。通过[问题模板](https://github.com/OXWWXO/static-isp-guide/issues/new/choose)提交脱敏内容；不要公开真实代理主机、凭据或订阅 URL。
