## ChatGPT / Claude 的公开反馈

六家最新的评测判断、正反用户反馈与日期统一见 [点评档案](reviews.md)。品牌评价和产品级测试分开；评测作者的推广关系也在该页说明。

### IPRoyal

- [Kerry 的学习笔记](https://kerrynotes.com/ai-traffic-routing/)：2026 年个人配置记录，涉及 Claude Code 403 问题与 IPRoyal ISP；称美国未指定地区约 $4。个人站点有推荐链接，非独立大样本对比。
- [Dallas 的 ChatGPT 使用记录](https://dallas.lu/zh-CN/iproyal-usa-static-residential-proxies/)：2023 年购买与成功截图，2026 年更新政策说明；含推广链接，成功截图不能当作 2026 年实时测试。
- [美国静态 ISP 评分变化](https://www.reddit.com/r/proxies/comments/1w2hgaa/iproyal_static_isp_scamalytics_score_went_020_40/)：2026-08 用户称四个月评分上升。评分上升不直接证明 AI 网站不可用。

### Proxy-Seller

- [NodeSeek 半年 Claude 记录](https://www.nodeseek.com/post-941494-1)：作者用 Proxy-Seller 美国静态住宅 IP 的账号正常使用约一个月后被封；另一 IPRoyal 账号也曾被封后解封。邮箱、付款、账号等条件不同，不能认定由代理导致，不能作为品牌对比实验。
- [Trustpilot 美国纽约 ISP 评价](https://www.trustpilot.com/review/proxy-seller.com?page=2)：2026-07 用户投诉维护期间 IP 被更换，商家承认技术维护可能需要换 IP。固定 IP 不等于任何情况下都不会变化。
- [Reddit FUP 帖](https://www.reddit.com/r/proxies/comments/1w75x4x/warning_proxysellers_hidden_100gb_fup_policy_zero/)：2026-09 用户投诉超额后超时、429；自称官方代表的账号说明每周期 100GB 后降低速度和并发，续费重置。回复身份未独立验证，具体 Mbps 未披露。
- [Trustpilot 主页](https://www.trustpilot.com/review/proxy-seller.com)：显示移除部分虚假评论的提示；不能把平台星级当作所有线路质量证明。
