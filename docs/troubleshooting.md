# 故障排查

| 现象 | 先查什么 | 处理方法 |
| --- | --- | --- |
| 入口本身不通 | 本地运营商、订阅过期、流量和入口限制 | 先修入口，ISP 不会修复第一跳 |
| 超时 | ISP 主机、端口、入口能否连到该地址 | 核对 HTTP/SOCKS5 端口；用另一正常入口比较；联系商家 |
| 认证失败 | 用户名密码、白名单、到期状态 | 白名单可能要填连接 ISP 的入口公网 IP，切入口后需重新确认 |
| 出口显示普通入口 | 顺序反了、规则未命中、客户端未接管 | 顺序为入口→ISP；查连接面板与最终配置 |
| 出口不断改变 | 买成动态住宅、仅网关固定、商家自动维护换 IP | 向商家确认网站看到的出口是否静态独享 |
| 网页可用，客户端不通 | 请求没被接管、额外域名或非 HTTP 流量 | 检查代理变量、TUN 和连接日志；补充相关域名 |
| Cloudflare 挑战 / 403 | 网站拒绝、域名限制、WAF、账号资格 | 保存错误主机与时间给商家；不要直接判定为封号 |
| 429 | 平台请求额度、并发、商家 FUP | 区分响应来自哪个服务；降低并发，查用量，不承诺换 IP 解决 |
| 视频慢但文本正常 | 两跳线路、FUP、拥堵、目标 CDN | 普通视频不要默认走 ISP；比较白天与晚间，查流量计量 |
| 更新订阅后配置丢失 | 修改了原始订阅，而不是自定义层 | 用编辑节点或扩展脚本；重新应用并校验 |
| DNS 循环 | 代理域名解析依赖代理本身 | 单独配置 proxy-server-nameserver；查看内核日志 |
| 脚本提示未知节点 | 节点重命名或 provider 键写错 | 对照原配置的精确键名；不要把策略组填成节点 |

## 支持请求示例

> 我需要一个美国独享静态 IPv4 ISP，期限 30 天，用于合法访问 chatgpt.com、claude.ai。请确认一个 IP 的最终费用、最低充值、网站限制、出口是否可能自动变化、FUP 后的具体带宽和并发，以及网站不能正常登录和发送消息时的更换/退款条件。

测试失败不必立即买第二个 IP。先核对链式方向、认证和域名规则，排除配置问题，再在商家的时限内请求支持。

公开求助时脱敏：订阅 URL、API key、代理密码、邮箱、Cookie、支付记录与订单号。HTTPS 会保护目标网站内容，但代理商仍可能知道访问目标；静态 ISP 不是匿名或免验证保证。
